# Exercise 9.01 Population Density Data Analysis Project
## Research Question
How has population density changed in Germany and Switzerland from 1960 to 2008, and how do their trends compare?

## Dataset
world_population.csv
This dataset is from CISC7204 Exercise 9.01, sourced from world bank population density records for educational use.
A copy of the dataset is stored in the Datasets folder. No personal, private or restricted data is included.

## Tools & Methods
Python, Pandas, Bokeh
Steps:
1. Load and reshape the world population density dataset
2. Extract time-series data for Germany and Switzerland
3. Create interactive visualisations using Bokeh: single line chart, combined comparison chart and linked subplots
4. Compare population density trends between the two countries

## Key Findings
Both Germany and Switzerland show a general upward trend in population density between 1960 and 2008. Germany maintained a higher population density than Switzerland across the whole period. Germany’s density grew quickly from 1960 to 2000 and then slightly fluctuated. Switzerland had steady continuous growth over these decades.

Limitation: The dataset only contains population density data and does not include factors such as migration rate or land-use changes. Therefore, we cannot fully explain the root causes of the density changes.
